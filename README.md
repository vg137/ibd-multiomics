# Causal Integration of Genetics and Single-Cell Transcriptomics in IBD

## Overview
This project integrates GWAS, eQTL, and single-cell RNA-seq data to identify
genes and cell types that causally mediate genetic risk for Crohn’s disease.

## Data Sources
- GWAS: IBD summary statistics (GWAS Catalog)
- eQTL: GTEx v8 (colon, blood)
- scRNA-seq: Human intestinal biopsy datasets (GEO)

## Methods
- SNP-to-gene mapping
- Cell-type–specific expression analysis
- Mendelian Randomization for causal inference
- Pathway and network interpretation

## Key Results
- Identification of candidate causal genes
- Localization of genetic risk to specific gut immune cell types
- Biologically interpretable pathways relevant to IBD

## Reproducibility
All analyses are reproducible using the provided environment and workflows.
