# Integration of Genetics and Single-Cell Transcriptomics in IBD

## Overview
This project integrates GWAS and single-cell RNA-seq data to identify
genes that might possess genetic risk for Crohn’s disease.

## Data Sources
- GWAS: IBD full summary statistics GCST90292538 (GWAS Catalog)
- Gene annotations: Gencode (GRCh38.p14)
- Gene expressions: RNA-Seq GSE57945 (GEO)
- Gene sets: Hallmark gene set (MSigDB)

## Methods
- SNP-to-gene mapping
- Gene set expression analysis

## Key Results
- Identification of candidate associated genes
- Biologically interpretable gene sets relevant to IBD

## Reproducibility
All analyses are reproducible using the provided environment and workflows.
